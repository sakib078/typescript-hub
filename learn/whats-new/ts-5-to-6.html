    TypeScript 5.x → 6.0

    TypeScript moves fast — roughly a release each quarter. Here's the recent arc you should know.

    The 5.x highlights

  1. 5.0 — standard (TC39) decorators and const type parameters.
  2. 5.2 — using declarations for explicit resource management.
  3. 5.4–5.6 — better inference, the NoInfer utility, and stricter checks for safer code.
  4. 5.9 — stabilized decorator metadata work and build-performance gains.

    5. TypeScript 6.0 (March 2026)

    The last release built on the original JavaScript codebase, and a milestone for defaults:

  5. strict is on by default — the ecosystem has fully embraced strict typing.
  6. Default target moved to ES2025 and module defaults modernized.
  7. Significantly faster incremental rebuilds and lower memory use.

    8. The throughline: TypeScript keeps tracking JavaScript's evolution and nudging projects toward safer defaults.
